# 키세카츠 링크 페이지

링크트리를 대체하는 한 장짜리 페이지. 모든 채널의 바이오·캡션에는 이 주소 하나만 넣고, 열면 지점별 네이버 플레이스 버튼 3개가 보인다.

- 주소: `https://link.kisekatsu.kr/` (GitHub Pages)
- 꼬리표: `?ch=채널` (ig·th·yt·tt·nc·x·lt·etc, 없으면 direct), `&c=YYMMDD-이름` (게시물에 링크를 넣을 수 있는 채널만)
- 현황판: `https://link.kisekatsu.kr/dash/` — 채널×지점 클릭, 매일 새벽 GA4에서 갱신
- 테스트: `npm test`
